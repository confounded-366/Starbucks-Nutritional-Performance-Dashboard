# Starbucks-Nutritional-Performance-Dashboard



Engineering an executive-ready Power BI dashboard for Starbucks ("Brewing Insights, Fueling Connections"). The solution provides a deep dive into beverage nutrition metrics—focusing on caloric impact, sugar content, caffeine concentration, and category-level product distribution across global markets.  

Project Goal
Analyze Starbucks' beverage portfolio to identify health-conscious offerings, evaluate caffeine and calorie distribution across categories, and optimize global product positioning for consumer preference mapping. 

Solution Provided
Nutritional Data Modeling: Transformed raw beverage attributes into standardized metrics (Calories, Sugar, Caffeine, Protein).  
Star Schema Design: Structured relational tables enabling real-time cross-filtering between categories, preparation types, and regional footprints.  
DAX KPI Architecture: Formulated custom DAX measures for category averages, beverage counts, and top caffeine-content rankings.  
Brand-Aligned UI/UX: Built an executive-grade dashboard using Starbucks' standard visual layout with high-visibility KPI cards and intuitive filtering slicers.  

Key Visuals Included
Executive KPI Cards: Total Beverage Options (31), Average Sugar (33g), Average Calories (198.29 kcal), and Average Caffeine (85.24 mg).  
Average Calories by Beverage Category Line Chart: Trend comparison across product lines like Frappuccino Blended, Signature Espresso, and Smoothies.  
Starbucks Global Presence Map: Geographic visual detailing global operational reach and density.  
Beverage Category Distribution Bar Chart: Volume analysis displaying item density per category.  
Average Caffeine by Category Donut Chart: Categorical percentage breakdown of caffeine intake across options (Total 230 mg reference metric).  
Top 5 Highest Caffeine Beverages Showcase: Visual cards highlighting high-caffeine products led by Coffee (200.75 mg), Classic Espresso (122.87 mg), and Frappuccino Blended variants. 

Features & Highlights
Dynamic Slicers: Header filters for Protein Range and Beverage Prep selection.  
Interactive Cross-Filtering: Clicking any category dynamically recalibrates calorie averages, caffeine levels, and global presence visuals.  
Custom Product Cards: Highlighting top caffeine-content SKUs with image assets and exact milligram metrics.
